# Amar Shinde Portfolio — editable HTML/CSS/JS

This is a **real HTML/CSS recreation**, not a full-page screenshot with invisible click targets. The hero photo is an actual `<img>` element; text, navigation, cards, buttons, technology stack, mock project previews, neon orbits and backgrounds are independent HTML/CSS.

## Run
Open `index.html` in a browser or use VS Code Live Server. Deploy the entire folder to Netlify.

## Customize
- `index.html`: edit text, project links, contact details, and sections.
- `styles.css`: layout, neon effects, responsive styles, animations.
- `script.js`: mobile menu and navigation.
- `assets/amar-portrait.png`: replace with your favorite photo.
- To activate Download CV, place your PDF at `assets/Amar-Shinde-CV.pdf`.
- Replace GitHub placeholder project URLs with the individual project URLs.
- Some project/experience details were transcribed from the supplied visual reference; verify before publishing.

The original reference image is not used as a page background.
